{%- comment -%} A display-ready table from _data (scripts/enrollment/prepare.mjs writes them): include.table = {caption, columns: [...], rows: [{rule?, cells: [{t, b?}]}]}. The first cell of each row is a row header. The wrapper is a focusable, labelled scroll region so keyboard users can scroll a wide table. table.sortable: column headings become sort buttons (assets/js/charts.js), each cell carries its sort value `v` as data-v, and table.sortedBy names the column the rows arrive sorted by (ascending). Without JS the table just shows in that order. {%- endcomment -%}
